## CORE C12 — PROMPT MASTER

### 1. Contexto

Estás desarrollando una aplicación llamada Core C12.

Es una calculadora comercial profesional orientada a uso en campo.

Debe ser:

- rápida
- clara
- funcional
- usable en móvil, iPad y escritorio

### 2. Alcance

La app incluye:

- calculadora base
- módulo IVA
- selector de decimales
- módulo de márgenes comerciales

### 3. Módulo márgenes comerciales

Debes implementar un bloque que permita:

- introducir un costo
- pulsar un margen
- obtener precio de venta inmediato

### 4. Botones obligatorios

- 20%
- 25%
- 30%
- 35%
- 40%
- 45%

### 5. Fórmula obligatoria

Precio venta = costo / (1 - margen)

No usar incremento porcentual simple.

### 6. Reglas de diseño

- una sola pantalla
- orientación horizontal
- estética tipo calculadora profesional
- integración natural del módulo

### 7. Reglas UI

El bloque de márgenes:

- debe estar agrupado
- enmarcado con línea amarilla
- etiqueta visible

### 8. Reglas de uso

Flujo:

1. usuario introduce valor
2. pulsa margen
3. ve resultado inmediato

### 9. Restricciones

No incluir:

- menús
- popups
- pasos adicionales
- configuraciones ocultas

### 10. Consistencia

El resultado debe poder usarse en:

- operaciones básicas
- cálculos de IVA

### 11. Regla final

Si algo reduce:

- velocidad
- claridad
- utilidad

Debe simplificarse.
