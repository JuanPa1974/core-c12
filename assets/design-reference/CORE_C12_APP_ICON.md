# CORE C12 — MASTER APP ICON

## Dirección aprobada

Propuesta oficial:

**OPCIÓN C**

## Concepto visual

El icono debe representar Core C12 mediante:

- bloque compacto
- identidad `C12`
- inspiración sutil en calculadora profesional
- seis teclas inferiores
- geometría robusta
- mínima cantidad de detalles
- reconocimiento inmediato

## No incluir

- AndaraLab
- slogan
- texto pequeño
- porcentajes
- símbolos fiscales
- engranajes
- elementos decorativos innecesarios

## Jerarquía

Elemento dominante:

`C12`

Elemento secundario:

seis teclas inferiores.

## Formato maestro

Crear posteriormente en Affinity:

`core-c12-master.afdesign`

Exportaciones maestras:

`core-c12-master.svg`

`core-c12-master-1024.png`

## Ubicación

    assets/app-icon/master/

## Documento maestro

- proporción 1:1
- lienzo de referencia: 1024 × 1024 px
- espacio de color: sRGB
- diseño vectorial
- alta legibilidad
- zona segura interna
- sin dependencia de esquinas físicas específicas

## Validación mínima

Comprobar visualmente el icono en:

- 1024 px
- 512 px
- 180 px
- 96 px
- 64 px
- 48 px
- 32 px

Si pierde reconocimiento a 48 px, debe simplificarse.
