# CORE C12 — SISTEMA VISUAL APROBADO

## Dirección general

Core C12 debe transmitir:

- herramienta profesional
- precisión
- velocidad
- claridad
- tecnología
- uso comercial en campo

No debe parecer:

- una calculadora infantil
- una app genérica
- una interfaz excesivamente futurista
- un producto gaming
- una calculadora científica compleja

## Estética

- fondo oscuro
- contraste alto
- acentos azules
- geometría limpia
- botones grandes
- apariencia profesional
- inspiración en calculadoras físicas premium
- lenguaje visual contemporáneo

## Jerarquía

Prioridad visual:

1. Display
2. IVA / motor fiscal
3. Márgenes
4. Teclado numérico
5. Acciones secundarias

## Principios UX

- una sola pantalla
- landscape-first
- máximo dos acciones para cálculos comerciales principales
- sin menús complejos
- sin ventanas innecesarias
- memoria muscular
- botones táctiles amplios
- lectura instantánea

## Iconografía

Los iconos funcionales deben ser:

- SVG
- vectoriales
- lineales
- modernos
- esquinas/extremos redondeados
- grosor consistente
- compatibles con `currentColor`
- sin emojis
- sin iconos Unicode
- sin sombras internas
- sin efectos 3D

## Icono de configuración

NO utilizar la rueda dentada tradicional.

Utilizar concepto visual:

- sliders
- adjustments
- tune controls

Debe comunicar:

**personalizar / ajustar**

y no simplemente "ajustes generales".
