# CORE C12 — DESIGN REFERENCE

Esta carpeta constituye la fuente oficial de referencias visuales y decisiones de diseño de Core C12.

## Propósito

Centralizar el contexto necesario para diseñar, revisar e implementar:

- icono oficial de la aplicación
- iconografía funcional
- identidad visual
- assets PWA
- assets iOS
- assets Android

## Herramientas previstas

- Affinity → creación vectorial maestra
- Canva → mockups y material visual
- Astra / ChatGPT → dirección de diseño y validación
- Claude Code → integración técnica de assets

## Regla

Los archivos contenidos en esta carpeta son referencias de diseño.

NO deben utilizarse directamente como assets runtime salvo aprobación expresa.

Los assets finales de producción deben almacenarse en:

- `assets/app-icon/`
- `assets/ui-icons/`
- `assets/branding/`
- `icons/` únicamente cuando corresponda a integración operativa

## Identidad aprobada

La propuesta seleccionada para el icono oficial de Core C12 es:

**OPCIÓN C**

Concepto:

- símbolo `C12`
- geometría inspirada en una calculadora profesional
- bloque superior dominante
- seis teclas inferiores
- diseño simple
- alto contraste
- reconocimiento rápido a tamaños pequeños

## Referencias visuales

Las imágenes oficiales deben estar en:

`references/core-c12-visual-system-approved.png`

`references/core-c12-app-icon-option-c.png`

Si alguna falta, debe incorporarse antes de pedir a Astra o Affinity que reproduzca el diseño.
